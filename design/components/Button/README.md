# Button

Circle buttons, 48px, for the few touch actions on the face screen.

- Consumer provides: the glyph (+ ✓ × ❚❚) and the action.
- Primary: `ink` fill, `on-ink` glyph, `shadow-lift`. Dismiss: `surface`, no shadow. Active/pause: `accent` with `on-accent`.
- One primary per screen, bottom-right. Pressed/focus: 2px `ink` ring, 2px offset.
- Don't put words in buttons; the hint line on the card explains the action.
