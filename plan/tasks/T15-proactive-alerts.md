# T15 主动提醒（异动 → 转头看你）· 轨道 B + A · 阶段 1（**第一个要跑通的流程**）

**一句话：** 它不发通知，它转头看你。你不用盯盘，它替你盯；只有值得你看的时候，它才动。

## 提醒分级（"提醒阶梯"，卖点）

| 级别 | 什么时候 | 机器人做什么 |
|---|---|---|
| 0 安静 | 普通波动 | 只在屏幕上更新数字，不动 |
| 1 瞥一眼 | 接近阈值（阈值的 70%） | 熊猫眼睛往你这边看 / 耳朵动一下（只有屏幕动画） |
| 2 转头 | 触及阈值（按人格：±1% / ±2% / ±3%） | **转头看你** + 异动卡（整屏）+ 字幕 |
| 3 叫你 | 5 分钟急涨急跌、放量（量比 ≥ 阈值）、触及涨跌停 | 转头 + 点头 / 摇头 + 提示音 + 喇叭念字幕 |

- 阈值来自 `brain/personas.json` 的 `standard`（标准：2% 转头、1.4% 瞥一眼、5 分钟 1% 急涨急跌）。人格（T16）先搁置。
- **10-30 真实数据实测（standard）：** 运行 `uv run python scripts/alert_replay.py standard`。
- 同一只股票同一方向同一级别**只提醒一次**（回放循环时重置）；一次提醒后冷却 `cooldown` 秒。

## 做什么
- [ ] `brain/alerts.py`：`AlertWatcher(persona).check(day, i) -> list[Alert]`，纯函数风格，可单测。Alert = `{code, name, level, kind, pct, text, say, facts}`；`kind = cross|surge|volume|limit`。
- [ ] `hub/modes.py`：把 `_watch_loop` 里内联的 ±2% / ±3% 判断换成 `AlertWatcher`；级别 ≥2 推 `mkt` 异动卡（带 `say` 字幕）+ `gesture look`；级别 3 加 `chime` 和点头 / 摇头（涨点头、跌摇头）。
- [ ] 卡片上加"想知道为什么？"——点一下 = `{"t":"ask","text":"<股票>为什么<涨/跌>"}`（衔接剧本 2）。
- [ ] 板子：`gesture look` = 从"看着你的显示器"的休息姿势（偏航 +12°）转回正对你，停 3 秒，再转回去（依赖 T01 的 ID1 定基准）。没有舵机时：屏幕上熊猫转头动画。
- [ ] 模拟器：收到 `gesture` 时屏幕预览上显示动作图标（↻ 转头 / ↕ 点头 / ↔ 摇头）。

## 验收
- [ ] `tests/test_alerts.py` 全绿（阈值、去重、冷却、分级、人格差异）。
- [ ] 回放 10-30（speed 1）：稳健型人格整天提醒次数 ≤ 3，冲浪手 / 闪电型更多（记录实际数字）。
- [ ] 真机：异动时转头 + 异动卡 + 字幕，端到端 < 1 秒。
