# T18 用语音 / 触摸增删自选 · 轨道 B + C · 阶段 1–2（**确定进演示**）

**一句话：** "把比亚迪加到自选" → 点头 + 列表里多一行；"删掉招商银行" → 点头 + 少一行；做不到 → 摇头 + 说为什么。

## 语音（路由新意图，T04）
| kind | 例句 | 结果 |
|---|---|---|
| `watch_add` | 把比亚迪加到自选 / 加一下宁德时代 / 关注中芯国际 | `profile.set watch.codes` 末尾加上 |
| `watch_remove` | 删掉招商银行 / 不看茅台了 / 把比亚迪移出自选 | 从 codes 里去掉 |
| `watch_list` | 我的自选有哪些 | 切到 `list` 模式 |

- 股票名识别、拼音纠错、别名和 T04 共用。**"它"/"这只"**指上一轮或当前屏幕上的股票（看到异动卡时说"加到自选"就加这只）。
- 复用现有的 `ModeEngine.profile_set({"watch":{"codes":[…]}})`：已经有名称解析、上限 8 只、保存、广播、模式重启。

## 动作和反馈
| 情况 | 动作 | 字幕 |
|---|---|---|
| 加成功 | 点头 1 次 | 「已加入自选：比亚迪（第 6 只）」 |
| 删成功 | 点头 1 次 | 「已移出自选：招商银行」 |
| 已经在 / 本来就没有 | 摇头 1 次 | 「比亚迪已经在自选里了」 |
| 满 8 只 | 摇头 1 次 | 「自选最多 8 只，先删一只？」 |
| 认不出股票 | 摇头 1 次 | 「没找到"火星科技"」 |
| 删到只剩 0 只 | 摇头 1 次 | 「至少留一只」 |

- 成功后屏幕切到 `list` 模式 3 秒，**新加的那一行高亮**（板子 `watch` 卡加 `hl` 字段 = 高亮的 code）。

## 触摸（备用）
- 自选列表里**长按一行 1 秒** → 弹出「移出自选？」→ 再点一下确认（板子上报 `{"t":"watch_remove","code":…}`）。
- 模拟器设置面板已经能编辑自选（现有功能），加个搜索框 + "加入"按钮即可。
