# T17 早报 / 收盘小结表 · 轨道 B + A/C · 阶段 2

**一句话：** 早上坐下来瞄一眼就知道昨天发生了什么；收盘时一张表总结今天。

## 现状
- `data/brief.py` 已有 `morning_brief()` / `close_summary()`，板子已有 `brief` 卡（一列文字条目）。这次升级成**表格**。

{"title":"收盘小结 · 10-30","cols":["","收盘","涨跌","量比"],

- 涨红跌绿；表头一行；最强 / 最弱一行加粗。

## 什么时候出现
- 由人格的 `brief` 决定：早报（开机或 9:00 后第一次有人按屏幕）/ 收盘（15:00 后）/ 每周五复盘。
- 休市日：早报 = 上一个交易日的收盘小结（今天就是这样：显示 10-30）。
- 语音："今天怎么样""给我个小结" → 路由到 `overview`，出这张表。
