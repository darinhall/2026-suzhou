# T09 麦克风 → 语音识别 · 轨道 A（a）+ B（b）· 阶段 2

## T09a 板子
- [ ] **按住说话**：在答案卡 / 盯盘屏的任意位置按住 > 0.3 秒 → `mic_start(trigger=touch)` → 每 50 ms 发一帧 → 松手 `mic_end`。最长 8 秒。
  - 注意和现有手势冲突：单击（下一项）、长按右上 0.7 秒、长按左上 1.2 秒。**按住说话只在屏幕中间区域生效**。
- [ ] 24 位采样 → s16le（右移 8 位，加软件增益，饱和截断）。
- [ ] 音量检测触发（`trigger=vad`）：用现有的开始 / 结束判定，加开关 `{"t":"voice","vad":true|false}`，**默认关**。
- [ ] 录音时屏幕 "在听" + 右下角音量条（已有）。

## T09b 中枢 `brain/asr.py`
- [ ] 收二进制帧拼成 PCM → `mlx_whisper.transcribe(language="zh", initial_prompt="以下是普通话的股票问答。宁德时代、比亚迪、贵州茅台、中芯国际、招商银行、创业板。")`。
- [ ] 繁体 → 简体（`opencc` 或简单映射）。
- [ ] 识别结果先广播 `ask_state listening text=…`（模拟器和屏幕显示"你说的是：…"），再进 `Brain.ask`。
- [ ] 空结果 / 太短 → 摇头 1 次 + "没听清"。
- [ ] 浏览器麦克风（T10）也走同一个入口。
- [ ] 测试：`tests/test_asr.py` 用 `tests/fixtures/audio/*.wav`（用 `say` 合成的剧本问题）验证识别 + 纠错后路由正确。

## 验收
- [ ] 安静环境：剧本三个问题，各说 3 次，至少 8/9 次路由正确。
- [ ] 嘈杂环境（放一段人声背景）：记录成功率；低于 6/9 就展台用浏览器麦克风。
