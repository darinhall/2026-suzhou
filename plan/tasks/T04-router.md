# T04 意图路由 `brain/router.py` · 轨道 B · 阶段 1

**目标：** 一句话 → `Intent(kind, codes, period_days, lang)`。**规则先上，LLM 只兜规则认不出的。**

## 意图
| kind | 例句 | 说明 |
|---|---|---|
| `yesno` | 宁德时代今天涨了吗 / 茅台跌了没有 | 含"吗 / 没有 / 是不是" + 涨跌词 |
| `quote` | 宁德时代怎么样 / 看一下比亚迪 | 一只股票 |
| `compare` | 比较宁德时代和比亚迪 / 和比亚迪比呢 | 两只；"和 X 比呢"用上一轮的股票 |
| `overview` | 今天大盘怎么样 | 指数 |
| `watchlist` | 我的自选谁最强 | profile 自选 |
| `explain` | 为什么 / 怎么回事 | 用上一轮的上下文 |
| `advice` | 我该买吗 / 全仓 / 能涨到多少 / 推荐一只 | **护栏**，摇头 |
| `control` | 下一只 / 切到自选 / 安静 | 转成现有 mode / mode_ctl 消息 |
| `watch_add` / `watch_remove` / `watch_list` | 把比亚迪加到自选 / 删掉招商银行 / 我的自选有哪些 | 见 T18 |
| `unknown` | 其他 | 交给 LLM 抽取；仍不行就摇头 + "我只懂行情" |

## 股票名识别
- 名字表：`data/names.py`（`search`）+ 常用别名（茅台→600519、宁王→300750、中芯→688981、招行→600036）。
- 语音识别的错字：拼音相似度（`pypinyin`）在名字表里找最近的，阈值内才认。
- 时间："今天"=1，"最近一周"=5，"一个月"=22，"今年"= 到年初；默认 22。
