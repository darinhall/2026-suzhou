# T10 模拟器问答面板 · 轨道 C · 阶段 1–2

**目标：** 控制台上能问、能看对话、能点追问；也是全部兜底的入口。

## 做什么（`sim/index.html` + 新 `sim/ask.js`）
- [ ] 输入框 + 发送 → `{"t":"ask","src":"sim"}`。
- [ ] **剧本按钮**：读 `brain/demo_questions.json`，一键发。
- [ ] **按住说话**（浏览器麦克风）：`getUserMedia` → 16 kHz s16le → 走 `mic_start` / 二进制 / `mic_end`，和板子一样。
- [ ] 对话记录：问题、识别文字、回答 `say`、动作图标（点头 / 摇头）、`provider` 和耗时小字。
- [ ] 追问 chips（`reply.followups`），点了就问。
- [ ] 语言切换 zh / en。
- [ ] 模拟器的屏幕预览渲染 `answer` 卡（T07 的模拟器部分）。

## 验收
- [ ] 不连板子，只开中枢 + 模拟器，剧本 1–3 能完整打字演一遍。
- [ ] 手机浏览器打开也能用（展台给评委自己点）。
