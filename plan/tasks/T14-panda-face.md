# T14 熊猫脸 + 黑白主题 · 轨道 A（板子）+ C（模拟器 / 设计）· 阶段 1–2

**目标：** 屏幕上的脸是一只熊猫，和黑白外壳统一；数据卡片也换成黑白主题。见 decisions.md §9。

## 设计（先在模拟器里定稿，再搬到板子）
- [ ] `design/tokens.json` 加 `panda` 主题：`ink`（墨黑，约 #1B1B1B）、`paper`（暖白，约 #F4F1EA）、`patch`（眼斑，= ink）、`up` 红 / `down` 绿不变、`warn` 黄。跑 `design/scripts` 生成 `tokens.css` + `deskbot_tokens.h`。
- [ ] `sim/face.js` + `screen.css`：熊猫脸 = 两只黑耳朵（上角的圆）+ 两块倾斜的椭圆眼斑 + 眼斑里现在的胶囊眼睛（白色）+ 小鼻子。所有表情保留：待机、眨眼、开心（眯眼）、在听（耳朵抖一下 + 声波）、思考（眼睛往上 + 三个点）、睡觉、玩球、**点头 / 摇头时脸也跟着动一下**（和舵机同步）。
- [ ] 在 `sim/lab.html` 里并排放 3 个版本给大家选（10 分钟内定）。

## 板子
- [ ] `ui.cpp`：眼斑和耳朵是静态的，画进背景 sprite；眼睛动画只重画眼斑内部（保持现在的局部刷新，不能变卡）。
- [ ] `screens.cpp`：卡片用 panda token。
- [ ] 过 `devColor()` 后拍照，确认暖白不发蓝。

## 验收
- [ ] 模拟器和板子并排拍照，看起来是同一只熊猫。
- [ ] 待机动画帧率不低于现在。
- [ ] 外壳 + 屏幕合照一张，给 PPT 用。
